
# COSMOS — Explore The Universe

Website edukasi luar angkasa dengan desain futuristik dan visualisasi planet 3D.

## Teknologi

- HTML5
- CSS3
- JavaScript
- Three.js
- OrbitControls

## Cara menjalankan

1. Buka folder project di Visual Studio Code.
2. Pastikan koneksi internet aktif.
3. Instal ekstensi Live Server.
4. Klik kanan index.html.
5. Pilih Open with Live Server.

## Struktur folder

cosmos-explore/
- index.html
- README.md
- css/style.css
- js/main.js

## Fitur

- Background luar angkasa.
- Delapan planet.
- Visualisasi planet 3D.
- Rotasi planet.
- Zoom dan drag.
- Informasi astronomi.
- Fakta luar angkasa acak.

## Catatan

Model planet menggunakan tekstur prosedural sederhana.
Skala planet tidak dibuat secara astronomis proporsional.
Untuk meningkatkan realisme, tambahkan tekstur permukaan
planet dari sumber astronomi tepercaya.
